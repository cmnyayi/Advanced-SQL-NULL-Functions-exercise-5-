# Advanced-SQL-NULL-Functions-exercise-5-
Advanced SQL NULL Functions project demonstrating data cleaning, missing value handling, and data transformation using IFNULL(), ISNULL(), and COALESCE() functions.

# Project Overview
This project focuses on handling missing and incomplete data using SQL NULL functions. The exercises cover practical business scenarios involving employees, customers, products, orders, payments, inventory, projects, reviews, and maintenance records. The goal is to ensure data accuracy and improve reporting by replacing NULL values with meaningful defaults.

# Objectives
Handle missing data effectively using SQL.
Apply NULL-handling functions in real-world datasets.
Improve data quality and reporting accuracy.
Create meaningful default values for incomplete records.
Perform data cleaning and transformation tasks.

# Skills Demonstrated
SQL Query Writing

IFNULL()

COALESCE()

# Key Tasks Completed
Replaced NULL salaries, grades, balances, and quantities with default values.
Identified records containing missing information.
Counted incomplete records across multiple datasets.
Calculated values using NULL-safe logic.
Displayed meaningful labels for missing customer and employee information.
Retrieved alternative values using COALESCE().
Standardized user preferences and maintenance logs.
Improved dataset consistency for reporting and analysis.
